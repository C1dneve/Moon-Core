# Moon Core Roadmap

The roadmap describes the planned evolution of Moon Core.

Each sprint represents a meaningful milestone in the development of the project.

Future plans may change as the project evolves.

---

## Current Status

- ✅ Sprint 0 — Foundation (Completed)
- ⏳ Sprint 1 — Core Engine
- ⏳ Sprint 2 — Workspace Manager
- ⏳ Sprint 3 — Widget Manager
- ⏳ Sprint 4 — Sidebar
- ⏳ Sprint 5 — CLI
- ⏳ Sprint 6 — Installer
- ⏳ Sprint 7 — Plugin System
- ⏳ Sprint 8 — Public Beta
- ⏳ Sprint 9 — Version 1.0

---

## Sprint 1 — Core Engine

### Goal

Create the technical foundation of Moon Core.

### Expected Deliverables

- Basic project structure
- Module loader
- Configuration loading
- Logging system
- First executable version

---

## Sprint 2 — Workspace Manager

### Goal

Allow users to create, save and switch between workspace profiles.

### Expected Deliverables

- Create workspace profiles
- Save workspaces
- Load workspaces
- Switch between workspaces

---

## Sprint 3 — Widget Manager

### Goal

Allow users to enable, disable and configure widgets inside a workspace.

### Expected Deliverables

- Enable widgets
- Disable widgets
- Configure widgets
- Save widget settings
- Load widget settings

---

## Sprint 4 — Sidebar

### Goal

Provide a customizable sidebar for quick access to workspace actions.

### Expected Deliverables

- Sidebar layout
- Quick action buttons
- Workspace switch button
- Power menu
- Sidebar customization

---

## Sprint 5 — CLI

### Goal

Allow users to control Moon Core through the command-line interface.

### Expected Deliverables

- Workspace switching commands
- Widget management commands
- CLI customization
- Help command

---

## Sprint 6 — Installer

### Goal

Allow users to install and configure Moon Core with minimal setup.

### Expected Deliverables

- Installation wizard
- Dependency checker
- Automatic tool installation
- Initial workspace selection
- First-time setup

---

## Sprint 7 — Plugin System

### Goal

Allow developers to extend Moon Core through independent plugins.

### Expected Deliverables

- Plugin loader
- Plugin API
- Plugin management
- Plugin documentation
- Example plugin

---

## Sprint 8 — Public Beta

### Goal

Release the first public beta of Moon Core.

### Expected Deliverables

- Public beta release
- Initial documentation
- Bug reporting system
- User feedback collection
- Known issues list

---

## Sprint 9 — Version 1.0

### Goal

Release Moon Core 1.0.

### Expected Deliverables

- Stable release
- Documentation
- Installation guide
- Changelog
- Release notes
- Bug fixes
