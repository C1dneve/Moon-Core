# 🌙 Moon Core

> **The modular workspace engine for Windows.**
>
> Build personalized workspaces by connecting the best Windows customization tools into a single, organized and extensible ecosystem.

Moon Core is an open-source workspace engine that helps users organize, customize and automate their Windows desktop experience.

Instead of replacing existing tools, Moon Core integrates them into a unified workspace system focused on productivity, modularity and performance.

---

## Planned Features

Moon Core is being built around a modular architecture.

The following features are planned for future releases:

- Modular workspaces
- Workspace profiles
- Widget management
- Customizable sidebar
- Command-line interface (CLI)
- Plugin system
- One-click installer
- High-performance architecture
